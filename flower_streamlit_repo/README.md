# Flower Image Classifier

A simple image-classification web application built with:

- TensorFlow
- MobileNetV2 transfer learning
- Streamlit

The model classifies five flower categories:

- daisy
- dandelion
- roses
- sunflowers
- tulips

## Project files

```text
flower_streamlit_repo/
├── .streamlit/
│   └── config.toml
├── .gitignore
├── README.md
├── class_names.json
├── requirements.txt
├── streamlit_app.py
├── train_model.py
└── flower_classifier.h5   <-- generated by train_model.py
```

## 1. Create a virtual environment

Windows:

```bash
python -m venv .venv
.venv\Scripts\activate
```

Linux/macOS:

```bash
python3 -m venv .venv
source .venv/bin/activate
```

## 2. Install dependencies

```bash
pip install -r requirements.txt
```

## 3. Train and save the model

```bash
python train_model.py
```

After training, you should have:

```text
flower_classifier.h5
class_names.json
```

## 4. Run Streamlit locally

```bash
streamlit run streamlit_app.py
```

Then open the local URL printed by Streamlit.

## 5. Push to GitHub

```bash
git init
git add .
git commit -m "Add flower image classifier Streamlit app"
git branch -M main
git remote add origin https://github.com/YOUR_USERNAME/flower-image-classifier.git
git push -u origin main
```

Replace `YOUR_USERNAME` with your GitHub username.

## 6. Deploy on Streamlit Community Cloud

1. Sign in to Streamlit Community Cloud with GitHub.
2. Create a new app.
3. Select your GitHub repository.
4. Select the `main` branch.
5. Use `streamlit_app.py` as the app file.
6. Deploy.

The model file `flower_classifier.h5` must be committed to the repository unless you change the app to download the model from external storage.

## Notes

The saved model already contains MobileNetV2 `preprocess_input()`. The Streamlit app therefore only resizes the uploaded image and converts it to a NumPy array before calling `model.predict()`.
